# Agente de IA para el análisis de datos 
Implementación de un agente de análisis de datos para tablas Excel del tipo CSV

### Requisistos 
  * Python3
  * seaborn
  * matplotlib
  * numpy
  * streamlit
  * groq
  * scipy
  * scikit-learn
### Ejecución
stremlit run asistente.py
